# Kids Star Sticker Rewards

A fun, colourful web app for parents and kids to track good behaviour using custom star rewards.

🌟 Built with HTML, CSS, JavaScript (jQuery)  
🎨 Features pastel smiling avatars, toast notifications, editable star types, automatic prize ticks, and a child-friendly interface.

---

## 🎮 Demo

Try it live:  
https://selectedtopicsit.github.io/kids-star-sticker-rewards/

---

## ⭐ Features

### 👦 Add Kids  
- Choose from 12 pastel emoji-style avatars (now all smiling!)  
- Inline editing  
- Delete or reorder kids (move up / move down)

### ⭐ Star Types  
- Pre-made categories (Kindness, Routine, Helping, Study, Sharing, Respectful, Clean Up Time)  
- Each includes a colour, meaning, and goal count  
- Create your own custom star types (name, meaning, colour, prize count)  
- Inline editing and deletion  
- Automatic syncing: all kids instantly receive new star counters  

### ✨ Star Tracking  
- Increase or decrease star counts using + / – buttons  
- Automatic ✓ ticks appear when goals are reached  
- Clean toast notifications when adding, updating, or awarding stars  

### 💾 Data & UI  
- Data saved automatically using LocalStorage  
- Responsive, child-friendly interface  
- Reset all data with one button  

---

## 🚀 Usage

1. Download or clone the repo  
2. Open **`index.html`** in your browser  
3. Add kids, select avatars, create star types, and track rewards  
4. Click **Reset** (top right) to clear all saved progress
